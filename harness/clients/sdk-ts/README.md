# `@orrery/client`

The TypeScript half of the client SDK: `AguiSession` (decode, `seq`, re-attach `since`,
control RPC) and `SurfaceStore`. **Pure data, no drawing** — exactly the same two things
[`../sdk-rs`](../sdk-rs) gives Rust, built on stock `@ag-ui/client`'s `HttpAgent` over SSE.

Types come from [`@orrery/protocol`](../../protocol), which is generated by
`cargo xtask typegen` and must not be hand-edited.

**Status.** Scaffold only, and `private` until there is something to publish.
Implementation plan: [`harness/docs/plans/08-protocol-transport.md`](../../docs/plans/08-protocol-transport.md).

It passes the shared fixtures in [`../conformance`](../conformance), the same ones
`orrery-client` runs in Rust.
