The orrery command tree. Links the ratatui and json clients.

Usage: orrery [OPTIONS] [COMMAND]

Commands:
  run          Run one turn, print the final text, and exit
  serve        Start a kernel, print its endpoint, and keep running without a client
  attach       Attach a renderer to a running kernel
  replay       Re-emit a stored session as events, so any renderer can draw any past session
  session      Inspect stored sessions
  install      Install an extension. A bare name is the signed registry
  remove       Remove an installed extension
  ext          Inspect and manage extensions
  permissions  Explain a permission decision
  config       Explain resolved configuration
  init         Write a starter configuration into the workspace
  import       Import configuration from another harness
  eval         Run, compare and replay evaluation suites
  ledger       Query the decision ledger
  telemetry    Query the telemetry stream
  help         Print this message or the help of the given subcommand(s)

Options:
      --profile <NAME>
          Which profile to resolve

      --workspace <PATH>
          The workspace root. Defaults to the current directory

      --ui <UI>
          Renderer. Defaults to ratatui on a tty, json otherwise

          Possible values:
          - ratatui: The default TUI, linked into this binary (`orrery-client-ratatui`)
          - ink:     The React/Ink TUI, spawned as a Node process
          - json:    Line-delimited AG-UI events on stdout

      --json
          Shorthand for `--ui json`

      --consent <MODE>
          Override the profile's consent mode, within the managed clamp

          Possible values:
          - always: Ask every time
          - once:   Ask once per matching call, then remember for the session
          - never:  Never ask: deny instead, so CI cannot hang

  -v...
          Log level on stderr. Never mixed into `--json` stdout. Repeatable

      --provider <SPEC>
          Where the model comes from. Repeat it for one stream per pass, the last repeating. This build understands `fixture:<path-to.jsonl>`

      --state-dir <PATH>
          Where the session database lives. Defaults to `<workspace>/.orrery`

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
