Query the decision ledger: what was asked, what was decided, and which rule decided it

Usage: orrery ledger [OPTIONS]

Options:
      --profile <NAME>
          Which profile to resolve

      --session <ID>
          Only this session's stream. Without it, every session in the state directory, oldest first

      --subject <SUBJECT>
          Only decisions by this subject: `agent`, `ext:<id>`, `agent:<name>`

      --workspace <PATH>
          The workspace root. Defaults to the current directory

      --rule <RULE>
          Only decisions naming this rule, by id or by the text it was written as

      --ui <UI>
          Renderer. Defaults to ratatui on a tty, json otherwise

          Possible values:
          - ratatui: The default TUI, linked into this binary (`orrery-client-ratatui`)
          - ink:     The React/Ink TUI, spawned as a Node process
          - json:    Line-delimited AG-UI events on stdout

      --json
          Shorthand for `--ui json`

      --stream <STREAM>
          Only one stream. Without it, every stream that carries a decision: what was loaded and what was refused as well as what was allowed

          Possible values:
          - load:      What loaded, what degraded and what was refused
          - audit:     Decisions, calls and consent. The evidence stream
          - telemetry: Counts and timings. Also `orrery telemetry`

      --consent <MODE>
          Override the profile's consent mode, within the managed clamp

          Possible values:
          - always: Ask every time
          - once:   Ask once per matching call, then remember for the session
          - never:  Never ask: deny instead, so CI cannot hang

  -n, --limit <N>
          Show at most this many, counted from the end

  -v...
          Log level on stderr. Never mixed into `--json` stdout. Repeatable

      --provider <SPEC>
          Where the model comes from, as `<kind>:<what>`: `fixture:<path.jsonl>`, `anthropic:<model>[@<url>]`, `openai-compat:<model>@<url>`, or its `ollama:` / `vllm:` aliases. Only `fixture:` repeats, one stream per pass, the last repeating. Without it, a `[provider]` table decides

      --state-dir <PATH>
          Where the session database lives. Defaults to `<workspace>/.orrery`

  -h, --help
          Print help (see a summary with '-h')
