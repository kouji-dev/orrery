Install an extension. A bare name is the signed registry.

Seven source forms, disambiguated by prefix, in the one vocabulary `orrery registry add --source` also speaks: `name`, `name@1.2.0`, `github:owner/repo#ref`, a git URL, `crates-io:<name>` (also spelled `crate:<name>`), `npm:<name>`, and a path — `./path`, `../path`, `file:path` or an absolute one.

Usage: orrery install [OPTIONS] <SOURCE>

Arguments:
  <SOURCE>
          What to install

Options:
      --profile <NAME>
          Which profile to resolve

      --to <LAYER>
          Which layer to install into. Defaults to the user layer.
          
          Spelled `--to` rather than `--workspace` because `--workspace <PATH>` is already a global flag naming the workspace root.

          Possible values:
          - user:      `~/.orrery/extensions/<id>/`. Personal, and available in every project
          - workspace: `<workspace>/.orrery/extensions/<id>/`. Committed with the repository

      --user
          Shorthand for `--to user`

      --workspace <PATH>
          The workspace root. Defaults to the current directory

      --link
          Symlink a local path instead of copying it: the development loop

      --ui <UI>
          Renderer. Defaults to ratatui on a tty, json otherwise

          Possible values:
          - ratatui: The default TUI, linked into this binary (`orrery-client-ratatui`)
          - ink:     The React/Ink TUI, spawned as a Node process
          - json:    Line-delimited AG-UI events on stdout

      --json
          Shorthand for `--ui json`

      --yes
          Grant everything the extension asks for without asking

      --consent <MODE>
          Override the profile's consent mode, within the managed clamp

          Possible values:
          - always: Ask every time
          - once:   Ask once per matching call, then remember for the session
          - never:  Never ask: deny instead, so CI cannot hang

      --force
          Replace an existing install rather than refusing

      --index <PATH>
          A signed index file to resolve registry names against

  -v...
          Log level on stderr. Never mixed into `--json` stdout. Repeatable

      --provider <SPEC>
          Where the model comes from, as `<kind>:<what>`: `fixture:<path.jsonl>`, `anthropic:<model>[@<url>]`, `openai-compat:<model>@<url>`, or its `ollama:` / `vllm:` aliases. Only `fixture:` repeats, one stream per pass, the last repeating. Without it, a `[provider]` table decides

      --state-dir <PATH>
          Where the session database lives. Defaults to `<workspace>/.orrery`

  -h, --help
          Print help (see a summary with '-h')
